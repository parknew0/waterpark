>

## Figma에서 가져온 기준

전체 `Lo-Fi` 페이지 노드 `20:7`은 여러 화면을 담은 Canvas라 디자인 컨텍스트를 직접 반환하지 않았다. 메타데이터로 구현 대상 프레임을 찾은 뒤 다음 두 프레임의 디자인 컨텍스트를 직접 확인했다.

| 화면 | Figma 노드 | 반영 요소 |
| --- | --- | --- |
| 지도 홈 | `117:510` | 어두운 지도, 청록 마커, 상단 상태 카드, 안전 안내 |
| 내 차 위치 설정 | `123:1610` | 주소 검색, 가까운 순 목록, 주차장 카드, 바텀시트 |
| 온보딩 — 차량 보호 | `54:151` | 1/2 진행률, 서비스 설명, 자동차 이미지, `Next` |
| 온보딩 — 위치 동의 | `123:2151` | 2/2 진행률, 필수 위치 권한 설명, `Agree & Start` |

주요 토큰은 배경 `#001817`, 표면 `#2A2C2C`, 강조 `#00E8EC`, 보조 텍스트 `#B8C9C8`이다. 모바일 화면의 바텀시트 구조를 유지하고 넓은 화면에서는 지도와 검색 패널을 2열로 배치한다.

## 컴포넌트

| 컴포넌트 | 책임 |
| --- | --- |
| `AppHeader` | 서비스 제목과 브라우저 현재 위치 요청 |
| `ParkingMap` | Kakao 지도 또는 키 없는 로컬 미리보기 지도 |
| `ParkingSearchPanel` | 검색 폼, 데이터 출처, 로딩·오류·빈 상태 |
| `ParkingCard` | 주차장명, 주소, 거리, 유형, 주차면수 표시 |
| `useParkingSearch` | Kakao 검색과 공공데이터 폴백 전환 |
| `OnboardingCarView` | 차량 보호 가치 제안과 다음 단계 이동 |
| `LocationConsentView` | 위치 권한 사용 목적 안내와 지도 진입 |
| `OnboardingProgress` | 2단계 온보딩 진행 상태 |

## 현재 포함하지 않는 것

- 침수 예측값과 안전 주차장 확정
- 로그인·차량 등록·푸시 알림
- 백엔드 API와 사용자 데이터 저장
- 실제 길찾기와 침수 우회 경로

주차장 표준데이터의 주차면수는 실시간 여석이 아니고 현재 후보는 안전 대피 장소로 검증되지 않았다. UI도 이 한계를 명시한다.
