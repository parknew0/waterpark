Figma 모션 컨텍스트에는 두 노드 모두 키프레임이 없었다. 따라서 화면의 위치·크기·색상은 디자인 컨텍스트를 기준으로 구현하고, 비와 진동은 사용자 요청에 따라 CSS 모션으로 별도 정의했다.

## 접근 경로와 전환

- 데모 주소: `http://localhost:5173/?view=emergency`
- 뒤로가기 버튼: 지도 화면 `?view=map`으로 전환
- `Move Your Car Now`: 저위험 경로 GeoJSON을 활성화하고 지도 화면 `?view=map`으로 전환
- 실제 운영에서는 위험 예측 API 또는 긴급 상태가 확정됐을 때 `emergency` 뷰를 여는 연결이 추가로 필요하다.

## 모션

### 비

- 26개 빗방울을 하나의 배열에서 생성한다.
- 각 빗방울은 위치, 길이, 속도와 음수 지연 시간을 달리해 동시에 시작한 것처럼 보인다.
- 화면 위에서 아래로 약간 기울어진 방향으로 반복 낙하한다.

### 경고 진동

- 전체 경고 아이콘은 1.15초 주기로 짧게 좌우 이동·회전하고 나머지 구간은 정지한다.
- 외곽 원은 같은 주기로 최대 1.07배 커지며 위험 신호를 보강한다.
- `prefers-reduced-motion: reduce` 환경에서는 전역 접근성 규칙에 따라 반복 모션을 사실상 중지한다.

## 데이터 한계

- `Estimated safe time: 30min`

경로 목적지는 공공주차장 후보이며 `safety_verified=false`다. 이는 실시간 주차 여석 또는 검증된 안전 대피소를 뜻하지 않는다. 백엔드 연결 전 발표에서는 반드시 프로토타입 값으로 설명한다.
