# Waterpark 침수 위험 산출 결과

> 확인일: 2026-08-22
>
> 상태: `FACT` — 학습표 생성, 모델 학습·평가, 규칙 기반 위험점수 산출까지 실제 실행 완료.

## 1. 결론부터

원래 목표였던 **지하주차장 침수 예측 모델은 학습할 수 없다.** 대신 다음 두 가지를 만들었다.

| 산출물 | 성격 | 상태 |
| --- | --- | --- |
| 지하주차장 위험점수 | 규칙 기반, 주력 | 25,336동 산출 완료 |
| 지표면 침수 XGBoost | 보조, 검증용 | 학습 완료, 일반화 실패 확인 |

**가장 중요한 발견: 단순한 지형 규칙이 XGBoost보다 성능이 좋다.**

| 방법 | 사건 단위 PR-AUC | 기준선 대비 |
| --- | ---: | ---: |
| 주변 대비 고도 규칙 하나 | **0.249** | 3.8배 |
| XGBoost 9개 변수 | 0.099 | 1.5배 |
| 무작위 (양성 비율) | 0.065 | 1.0배 |

## 2. 왜 지하주차장 침수를 학습할 수 없나

지하층이 있는 건물 25,336동을 침수흔적 Polygon과 겹쳐본 실제 결과다.

```text
침수 Polygon 안에 들어간 건물     176동 (0.69%)
그 중 지하주차장이 확정된 건물       9동
```

**양성 표본 9개로는 지도학습이 성립하지 않는다.**

근본 원인은 두 자료가 서로 다른 지역을 다루기 때문이다.

| 시군 | 침수 Polygon | 지하주차장 확정 |
| --- | ---: | ---: |
| 경산시 | 0 | 338 |
| 구미시 | 24 | 405 |
| 봉화군 | 134 | 4 |
| 경주시 | 587 | 194 |

침수흔적도의 침수 원인 1위는 `농경지 침수 및 농작물 피해, 하우스 파손`으로 312건이다. 이 자료는 **농경지와 하천 범람을 조사한 기록**이고, 지하주차장은 도심에 있다.

따라서 경산시 지하주차장 338동을 `침수 안 됨(0)`으로 두는 것은 사실이 아니라 **조사하지 않았다**는 뜻이다. 이는 [전처리 계획](./02-preprocessing-and-xgboost-feasibility.md) 3.3절이 금지한 처리다.

## 3. 대신 학습한 것: 지표면 침수

### 학습표

```text
한 행 = 건물 하나 × 호우 사건 하나
정답  = 그 사건에 이 건물 위치의 지표면이 침수됐는가
```

| 항목 | 값 |
| --- | ---: |
| 행 수 | 45,920 |
| 양성 | 2,993 (6.52%) |
| 사건 수 | 30개 중 양성 보유 21개 |

### 음성 라벨을 만든 규칙

침수 Polygon 밖이라고 전부 `0`으로 두지 않았다.

```text
같은 사건의 조사된 Polygon에서 1km 이내  → 음성 0
그보다 먼 건물                          → 학습에서 제외 (미확인)
```

조사 범위 안에 있었는데 침수되지 않은 건물만 음성으로 인정한 것이다.

### 데이터 누수 차단

| 제외한 변수 | 이유 |
| --- | --- |
| `distance_to_flood_polygon_m` | 양성은 전부 0이라 정답 그 자체 |
| `longitude`, `latitude` | 같은 건물이 여러 사건에 등장하므로 좌표를 외울 수 있음 |

분할도 무작위로 하지 않고 사건 단위와 건물 단위로 각각 나눴다.

### 평가 결과

| 분할 방식 | PR-AUC | ROC-AUC | 재현율 | 의미 |
| --- | ---: | ---: | ---: | --- |
| 사건 단위 CV | 0.099 | 0.674 | 0.060 | **새로운 호우에 일반화 실패** |
| 시간 순서 (≤2018 → 2019+) | 0.104 | 0.644 | 0.256 | 마찬가지로 낮음 |
| 건물 단위 CV | 0.825 | 0.983 | 0.948 | 높아 보이지만 같은 사건이 양쪽에 있음 |

건물 단위 분할의 0.825를 성능으로 주장하면 안 된다. 같은 호우 사건이 학습·검증 양쪽에 들어가 있어, 모델이 그 태풍의 침수 지도를 보간한 것에 가깝다.

**사건 단위 0.099가 정직한 값이며, 이는 [전처리 계획](./02-preprocessing-and-xgboost-feasibility.md) 5절이 예측한 `독립 호우 사건 수가 매우 적음` 한계가 실제로 발생한 것이다.**

## 4. 강수량에서 신호가 나오지 않는 이유

실제 측정한 구간별 침수율이다.

| 24시간 누적 강수 | 침수율 | 표본 |
| --- | ---: | ---: |
| 0~50mm | 3.9% | 2,935 |
| 50~100mm | 9.6% | 7,331 |
| 100~150mm | 8.5% | 10,173 |
| 150~200mm | 3.7% | 14,852 |
| 200~300mm | 7.2% | 10,449 |

단조 증가하지 않는다. 저지대만 따로 보면 오히려 **비가 많을수록 침수율이 낮게** 나온다.

| 조건 | 비 적음(<100mm) | 비 많음(100~200) | 폭우(>200) |
| --- | ---: | ---: | ---: |
| 저지대(<2m) | 43.3% | 31.8% | 23.9% |
| 중간(2~10m) | 8.5% | 7.5% | 11.0% |
| 고지대(>10m) | 0.0% | 0.3% | 0.4% |

이는 비가 적을수록 안전하다는 뜻이 아니라, **한 사건 안에서는 모든 건물의 강수량이 같기 때문에** 이 표가 사실상 사건끼리를 비교하고 있다는 뜻이다. 사건이 21개뿐이고 사건마다 조사 범위가 달라 강수-침수 관계를 분리할 수 없다.

따라서 강수 기준은 학습하지 않고 **기상청 공식 호우특보 기준**을 그대로 쓴다.

## 5. 지형에서는 신호가 뚜렷하다

| 주변 대비 고도 | 침수율 | 표본 | 평균 대비 |
| --- | ---: | ---: | ---: |
| 0~2m | 35.5% | 1,452 | 5.5배 |
| 2~5m | 14.8% | 9,644 | 2.3배 |
| 5~10m | 5.2% | 19,126 | 0.8배 |
| 10~20m | 0.4% | 11,092 | 0.1배 |
| 20m 이상 | 0.0% | 4,236 | 0.0배 |

단조 감소하며 물리적으로도 타당하다. 이 관측값이 위험점수의 근거다.

## 6. 지하주차장 위험점수

### 구성

```text
지형 위험 (우리 데이터에서 관측한 침수율)
  + 과거 침수 구역 500m 이내면 한 단계 상향
  = 상시 위험도

× 실시간 강수 (기상청 공식 특보 기준)
  = 서비스가 사용자에게 보여주는 경보
```

위험도에는 **가능성만** 넣고 지하주차장 유무나 주차 대수는 넣지 않았다. 그것은 피해 규모이지 침수 가능성이 아니므로 별도 컬럼으로 뒀다.

### 강수 발령 기준 (기상청 공식)

| 단계 | 기준 |
| --- | --- |
| 호우주의보 | 3시간 60mm 이상 또는 12시간 110mm 이상 |
| 호우경보 | 3시간 90mm 이상 또는 12시간 180mm 이상 |
| 극한호우 | 1시간 50mm 이상이면서 3시간 90mm 이상, 또는 1시간 72mm 이상 |

지형 위험이 높은 건물일수록 낮은 단계에서 알린다.

### 산출 결과

지하층 보유 건물 25,336동의 상시 위험도다.

| 위험도 | 건물 수 |
| --- | ---: |
| VERY_HIGH | 341 |
| HIGH | 2,283 |
| MODERATE | 4,979 |
| LOW | 6,582 |
| VERY_LOW | 8,729 |
| UNKNOWN | 2,422 |

지하주차장이 확정된 1,787동 중 과거 침수 구역 안에 있는 건물은 9동, 500m 이내는 121동이다.

## 7. 반드시 지켜야 할 표현

| 하면 안 되는 말 | 대신 쓸 말 |
| --- | --- |
| 이 지하주차장이 침수됩니다 | 이 위치는 주변보다 낮아 지표면 침수 이력 지역과 조건이 비슷합니다 |
| AI가 침수를 예측합니다 | 과거 침수 기록에서 측정한 지형 위험도입니다 |
| 침수 확률 35% | 비슷한 지형에서 과거 조사 시 35%가 침수됐습니다 |
| 안전합니다 | 과거 조사 기록이 없습니다 |

마지막 항목이 특히 중요하다. 경산시처럼 침수 조사 자체가 없는 지역은 **안전한 것이 아니라 모르는 것**이다.

## 8. 한계

- 지표면 침수와 지하주차장 침수는 다른 사건이다. 후자를 기록한 자료는 확보하지 못했다.
- 침수흔적도는 2021년까지이며 원 제공기관이 갱신을 중단했다. 2022년 힌남노 기록이 없다.
- 조사 범위가 농경지·하천 중심이라 도심 지역 기록이 부족하다.
- 표고는 Copernicus GLO-30 DSM이라 건물과 수목 높이가 포함된다. 지반고가 아니다.
- 위험점수의 지형 구간은 침수 조사 지역 주변 1km에서 측정한 값이라 경북 전역의 절대 확률이 아니다.
- Overture 건물에는 준공연도가 없어, 사건 당시 존재하지 않았던 건물이 학습표에 포함될 수 있다.
- 지하주차장 판정은 필지 단위다.
